# Multi agent workflow 

## Orchestrating by code
Let create different sales agents 

1. Agent 1 -> Professional Sales Agent(email style is professional, serious, with gravitas and credibility)
2. Agent 2 -> Humorous Sales Agent(email style is witty, engaging, and humorous)
3. Agent 3 -> Executive Sales Agent(email style is concise, to the point, in the style of a busy senior executive)
4. Agent 4 -> Sales Manager (picks best email generated from previous 3 agents and uses tool to send the email)
